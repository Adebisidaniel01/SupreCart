SupreCart admin setup
====================

Local admin sign-in uses these demo credentials when no admin secrets are
configured:

  Username: timie_daniel
  Password: BlackRose

The ignored project-root .env file can override them with ADMIN_USERNAME and
either ADMIN_PASSWORD or ADMIN_PASSWORD_HASH. For deployment, configure the
same values in your hosting provider's server-side secret manager.

ADMIN_SESSION_SECRET is optional. When it is omitted, the admin session key is
derived from ADMIN_USERNAME and the configured password material. If you do set
it, use a unique random value of at least 32 characters.

Dashboard figures and activity are illustrative until live finance, account,
and analytics services are connected.
